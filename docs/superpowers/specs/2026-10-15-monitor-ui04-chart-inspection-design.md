## 三个可运行用户场景

### S1 多曲线按各自采集时间比较

先选择 A 并积累数据，再选择 B；B 的第一点显示在自身采集时刻，不能借用 A 的第一点时间。曲线长度、起点或缺口不同仍使用共同横坐标。保留空缺和读取错误，不补点、不插值成样本、不跨缺口连线。查看提示时可区分每条记录原始 UTC 时间和值。

### S2 图内操作与工具栏保持同一缩放窗口

使用图内滑块/内部缩放后，工具栏范围同步；再点击放大、缩小或重置，从这个范围继续。新样本、窗口 resize、实时/历史切换后回到实时页，不使缩放跳回旧值，也不新建订阅。已有 binding/run 或缺口引发的 reducer 重置仍有效。

反复放大到最小窗口后保持该窗口，不能因为端点相等而突然回到全图。百分比窗口宽度统一为 1–100 个百分点；按钮沿用每次两端各 10 个百分点的缩放步长（总宽度变化 20），以当前中心计算并限制宽度，必要时整体平移到 [0,100] 内。最小时禁用放大，全幅时禁用缩小；重置为 [0,100]。合法手势窗口小于 1 个百分点时按相同中心扩展为最小窗口；非法/反向范围忽略，保留当前有效范围。

缩放保持既有百分比窗口：它表示当前缓存时间域的比例，缓存增长或最早点淘汰时对应的绝对时刻可变化。本切片不提供冻结画面、绝对时间锁定或暂停采样的替代语义。

### S3 明确选择上限，并随时能移除已选曲线

工作台显示“已选择 N / 8 条曲线”和已选项，每一项都能移除；即使当前观测组数值表已不包含该项，入口仍可达。满 8 条时未选行的“显示曲线”禁用并有可见中文说明；已有曲线仍可隐藏，移除一条后可添加新项。无选择显示选择引导；已选择但尚无样本显示等待提示，不绘制演示点。

## 共同时间坐标与数据边界

1. `ChartPoint` 的 capturedUnixNs bigint、capturedAtUtc、value 与 segment 仍由既有采样 reducer/series 维护；每条最多 600 个缓存点、最多 8 条。API、原始缓存、导出及历史的纳秒值不变。
2. 图表 adapter 从当前可见曲线中具有真实时间的点计算共同 originNs（最小 capturedUnixNs）。真实时间点包括有时间但 value=null 的读取空缺；人工 continuity gap 的空 capturedAtUtc 与空值是断线标记，不能把其 0ns 当作 1970 年样本或用于时间域。
3. X 轴使用 value 坐标，每个真实点显式携带自己的相对毫秒值：先做 bigint 差值，再按 1,000,000n 分离整毫秒和余数后转为绘图 number。禁止先把绝对纳秒转 Number、经 Date 往返丢精度，或以另一曲线数组下标替代时间。signed-int64 全跨度的整毫秒仍在 JS 安全整数范围；浮点绘图坐标是展示近似，原始 ns 十进制串和 UTC 字符串保留供诊断/提示。
4. 图表明确标注“相对时间（ms）”及对应“起点（UTC）”。tooltip 每条记录显示该记录的原始 UTC、值和可查看的原始 ns；不把不同采集时刻说成同一个测量。用户标签按文本展示，不拼接成 HTML。轴范围由全部真实时间点决定，不依赖曲线排列顺序。
5. 不重排或重写原始缓存。相同时间点保持原有顺序，不因去重丢掉样本；series 使用稳定 watch key 作 id。遇到 gap 标记或 segment 变化，在相邻真实点之间保留 null 断线，`connectNulls=false`；人工空标记可锚定到前一真实点 X，位于首个真实点之前的标记不生成虚构坐标。单点、全空值和只有 gap 均有有限坐标域，不出现 NaN/Infinity 或 1970 伪点。
6. 无已选项、已选无真实样本、存在真实时间但无可绘制值分别给出中文空状态；有空值时不把错误值画成 0。现有 UI03 非最新提示和绑定/运行重置保留。

## 状态来源与事件生命周期

| 内容 | 唯一所有者 | 约束 |
| --- | --- | --- |
| 原始曲线、选择集合、连接/采样状态 | 既有 reducer/model | 不在 ECharts 或组件另存权威选中集合，不修改采样算法 |
| ZoomRange 百分比 | 既有 reducer.zoom | 工具栏和图内事件都进入现有 zoom.changed；不另建持久化 zoom |
| 时间投影与提示元数据 | chart adapter 的纯派生结果 | 从 DisplaySeries 计算，不回写样本、选组、drop 统计或历史 |
| ECharts 实例、handler、ResizeObserver | LiveChart 单次挂载生命周期 | 注册/解绑成对，dispose 后回调无效；更新不反复初始化 |
| 中文提示和上限文案 | presentation/zh | 不改机器字段或用户变量名 |

依赖保持组件 → reducer action / 图表 adapter → 既有模型；不引入新框架、存储库或数据服务。ECharts 仍只负责绘制和手势事件，既有 zoom 与 selection 状态拥有最终决定权。

- LiveChart 接入 `datazoom` 回调，通过最新 onZoom 传回标准化范围。接受完整、有限的 start/end 百分比；顶层具有配对字段时只校验该配对，未提供配对时取 batch 中首个有效配对。夹到 [0,100] 后须 start<end，否则忽略；再按 S2 扩展不足 1 个百分点的合法范围。缺失/非数值/过期回调不能重置有效窗口。
- reducer 与组件对相同范围保持幂等；程序性 setOption 更新使用静默路径且仅在实际范围改变时回传，避免更新环。ECharts 内部 transient 状态不能成为第二来源。绑定 handler 读取最新回调/范围，卸载解绑并拒绝迟到调用。
- 图例作为曲线说明，关闭 ECharts 独立的点击隐藏选择。显示/隐藏统一由数值表和已选曲线区触发现有 series.toggled；不可出现图例已隐藏但表格仍说显示、下一次采样又恢复的两份状态。
- 选择数量与禁用态从 reducer.selectedSeries 派生；reducer 的 8 条守卫保留为同步最后防线。新区域不能按当前表格行过滤已选项，否则切组后无法释放配额。未满上限时操作语义与 UI03 相同。
