## Observable directory contract

The existing DWARF reader is the sole address/type authority. A scalar qualifies only when the same unique selector resolves to the proved object, has an invariant fixed address, has a supported scalar type and size, and lies in readable project memory without a stack frame, CPU register or current-PC evaluation. AST metadata alone is never sufficient. Proven DWARF entries with unknown source storage classification may qualify when their scope and reader evidence establish these conditions; do not guess their role. Automatic locals/parameters remain excluded. Pointer values can qualify; implicit dereferencing is not introduced.

Maintain a private structural eligibility decision independent of `canAdd` and its runtime reason. Existing wire shapes, endpoints and request forms remain unchanged; there is no new all-declarations toggle. New default source pages are filtered server-side before query pagination and counts, including root flat pages, scope pages and aggregate children. Bump the catalog semantic identity so old cursors cannot survive the new meaning. Binding/source/ELF revalidation and selection admission remain authoritative.

Without a probe, project/ELF proof can establish structural eligibility; show `reason=probe_required`, `canAdd=false`, with Chinese label `待连接`. Once connected, current binding memory regions and all freshness checks still decide addition. A mismatched/changed binding must not be treated as disconnected and must never grant admission.

Aggregates are navigation containers, not directly sampleable variables. Keep them only when a valid scalar descendant is reachable within the existing depth6 and per-root4096 expansion bounds. Reject ambiguous member names, invalid selector components, bitfields and unsupported locations/types. Preserve independent branch navigation and bound CPU work/memory for deeply nested or million-element types; use homogeneous type/range reasoning where possible rather than enumerating conceptual array products. Truncation or inability to finish a bounded eligibility scan must remain explicit, not a false complete result. A page total counts the filtered entries in its admitted bounded set; do not expose an unfiltered conceptual count as the number of observable variables.

Prune file/scope/folder branches with no eligible root entries. This intentionally supersedes the earlier default full-file listing requirement. `variableCount` and page totals count visible variable entries, including aggregate containers and header aliases, not distinct scalar memory objects. UI calls them `变量条目`; compiled-debug and source coverage counts remain separate discovery diagnostics, not visible or sampleable counts.

The connected firmware-variable fallback must likewise not offer an aggregate/unsupported expression as a sampleable leaf. Use an opt-in scalar-only descriptor policy in the existing reader/Monitor call path, filtered before its pagination and bound into cursor identity. Preserve generic descriptor callers' existing default behavior. The source tree remains the offline browsing entry; the older connected-only fallback does not acquire a second offline catalog.

Keep a compact Chinese explanation accessible in the catalog: fixed-address globals/statics and readable members are supported; ordinary locals/parameters, optimized-out and unproved declarations are excluded. Empty/search/firmware-unavailable messages must distinguish their cause. Retain current hierarchy, successful-operation feedback, group draft deduplication, numeric/waveform layout and CSV behavior.

## Monitor connection contract

Reuse the existing worker/config/backend adapter. Add a closed internal `observe-preserve` connection policy. `ProbeWorkerConfig.for_observation(*, preserve_target_state: bool=False)` accepts an actual bool only; true selects that policy at the existing100kHz observation rate, false retains normal behavior. Monitor's production open opts in; hardware_workflows and CONTROL/MODIFY/recovery defaults do not change. Unknown policies and invalid combinations fail before backend access. Preserve-mode `halt_on_connect=True` is invalid before probe selection/opening.

Preserve mode uses pyOCD `connect_mode=attach`, `resume_on_disconnect=False`, disabled user/config scripts and disabled pack debug sequence execution. pyOCD0.45.1's option alone is insufficient: its sequence-presence checks can still suppress generic ADI/CortexM initialization when execution is disabled. In the existing `_DefaultPyOCDDriver.create_session`, immediately after constructing `Session(probe, auto_open=False, options=...)` and before returning/opening it, resolve `session.board.target` and clear its public `debug_sequence_delegate` property to None for this preserve-mode options combination. Verify the property is actually None and fail closed on an absent/incompatible target contract. Session constructs Board/PackTarget before open; DP/core initialization later propagates only a non-None delegate, so this restores generic ADI/CortexM attach fallback. No global monkeypatch or second driver is allowed. Validate this with the installed dependency, including sequence-presence checks and generic fallback, rather than only a fake whose implementation mirrors the patch. Inability to establish this path is a product blocker, not a reason to silently re-enable scripts or fall back to halt. A pack that requires custom initialization may report connection failure; never retry with a CPU-control mode.

No preserve-mode success, failure cleanup, close or recovery path may call halt/resume/reset or under-reset. Cleanup closes only owned resources and retains the existing diagnostic/lifecycle/lease/worker-stop proof. Target state may be read without changing it; an already halted target is accepted without pretending it is running. No automatic retry or mode fallback. Explicit normal CONTROL/MODIFY and under-reset behavior and their authorization remain unchanged.

This is a CPU-control contract, not a promise of zero electrical, timing, bus or debug-register effect. pyOCD may enable debug access; memory sampling consumes bus bandwidth. Unit/dependency adapter evidence is not physical proof that no transient stop occurs on a particular board. Do not label hardware evidence PASS.
